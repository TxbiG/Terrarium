## Windows build tools

Install the local build tools with:

```powershell
.\Scripts\install_build_tools.ps1 -AcceptAgreements
```

This installs CMake, Ninja, and LLVM/Clang through winget.



## Folder structure
- ```Documentation``` - Project documentation.
- ```resources``` - Images and Audio and some other data
- ```apps``` - Some applications that can be preinstalled
- ```boot``` - Bootloader
- ```kernel``` - Terrariums Kernel
- ```lib``` - Terrariums libraries
- ```services``` - User-space OS services
